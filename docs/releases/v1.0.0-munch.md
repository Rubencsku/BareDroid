# BareDroid v1.0.0-munch — First Release

This is the first public release of BareDroid: a full native Linux environment for Android phones without chroot, Termux, PRoot, containers or Android compatibility layers.

This initial release targets the Xiaomi POCO F4 / Redmi K40S (`munch`). It is an experimental developer release, not a general-purpose phone installer.

## Reference stack

| Component | Version or implementation |
| --- | --- |
| Kernel | Linux 6.19.6 with `-munch-ubuntu` local version |
| Device tree | `sm8250-xiaomi-munch.dtb` with board ID `<50 0>` |
| Userspace target | Ubuntu 26.04 ARM64 minimal server |
| Init | systemd 259 in the reference rootfs |
| Wi-Fi | QCA6390 using `ath11k_pci` |
| Recovery network | USB Gadget Ethernet at `172.16.42.1/24` |

## Published artifacts

The release is expected to contain:

| File | Purpose |
| --- | --- |
| `debian_mainline_boot_munch.img` | Header-v3 boot image with the kernel and ramdisk |
| `debian_mainline_vendor_boot_munch.img` | Header-v3 vendor boot image with DTB and command line |
| `debian_mainline_single_boot_munch.img` | Temporary-boot test image with an appended DTB |
| `Image-6.19.6-munch` | Uncompressed ARM64 kernel image |
| `sm8250-xiaomi-munch.dtb` | Compiled POCO F4 device tree |
| `modules-6.19.6-munch-ubuntu.tar.gz` | Matching kernel modules |
| `SHA256SUMS.txt` | Integrity hashes for release artifacts |

The historical `debian_` filename prefix does not describe the current Ubuntu userspace. It is retained in this release for compatibility.

## Important limitation

The release does not contain a complete Ubuntu root filesystem. Users must prepare an ext4 ARM64 rootfs on userdata by following [Root filesystem preparation](https://github.com/Rubencsku/BareDroid/blob/master/docs/rootfs.md).

## Flash summary

The release targets slot B and uses this `munch`-specific sequence:

```bash
fastboot erase dtbo_b
fastboot flash boot_b debian_mainline_boot_munch.img
fastboot flash vendor_boot_b debian_mainline_vendor_boot_munch.img
fastboot --set-active=b
fastboot reboot
```

Read [Installation](https://github.com/Rubencsku/BareDroid/blob/master/docs/installation.md) and [Recovery](https://github.com/Rubencsku/BareDroid/blob/master/docs/recovery.md) before running these commands.

## Known limitations

- Only the reference POCO F4 setup has been demonstrated.
- Rootfs provisioning is not automated in this release.
- The source build is not yet self-contained from a clean clone.
- The rescue initramfs exposes an unauthenticated Telnet shell over USB.
- Display, touch, Bluetooth, audio, cameras, cellular service and suspend are not release-supported features.
- Firmware redistribution and unified repository licensing still require maintainer review.

## Release verification

Keep all downloaded artifacts and `SHA256SUMS.txt` in one directory and run:

```bash
sha256sum -c SHA256SUMS.txt
```

Do not flash any file that fails verification.
