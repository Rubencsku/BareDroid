# BareDroid v1.0.2-munch — Validated Root Discovery

BareDroid v1.0.2-munch is a maintenance release for the Xiaomi POCO F4 / Redmi K40S (`munch`). It keeps the Linux 6.19.6 kernel, device tree and module set while making the Mainline initramfs work with both the reference storage layout and custom ext4 root partitions.

This remains an experimental developer release, not a general-purpose phone installer.

## Fixed

- Honor the kernel `root=` argument instead of unconditionally selecting `/dev/sda34`.
- Resolve direct device paths, `PARTUUID=` and `PARTLABEL=` without depending on udev or `blkid`.
- Probe ext4 candidates read-only and require an executable systemd or `/sbin/init` before selecting a root filesystem.
- Scan UFS partitions for a validated rootfs when the kernel argument and reference userdata paths are stale.
- Check that the final read-write mount succeeds before deploying files or calling `switch_root`.
- Retain the v1.0.1 `devpts` fix for the BusyBox Telnet rescue console.

These changes allow a custom root such as `/dev/sda39` to boot while keeping `/dev/sda34` as the documented reference default.

## Verify downloads

Keep all downloaded assets in one directory and run:

```bash
sha256sum -c SHA256SUMS.txt
```

Do not boot or flash files that fail verification.

## Non-destructive test

Enter Fastboot mode and load the single image into RAM:

```bash
fastboot boot debian_mainline_single_boot_munch.img
```

Verify the native boot:

```bash
cat /proc/1/comm
systemctl is-system-running
mount | grep ' on / '
```

PID 1 must be `systemd`; `running` or `degraded` confirms that systemd was started. The root mount should identify the selected ext4 partition.

## Update an existing slot-B installation

The update replaces only the slot-B boot-chain images. It does not require formatting userdata or reinstalling the root filesystem:

```bash
fastboot getvar product
fastboot getvar current-slot
fastboot flash boot_b debian_mainline_boot_munch.img
fastboot flash vendor_boot_b debian_mainline_vendor_boot_munch.img
fastboot --set-active=b
fastboot reboot
```

Confirm that `fastboot getvar product` reports `munch` before flashing. A fresh installation must follow the complete [installation guide](../installation.md), including its DTBO and rootfs preparation requirements.

## Security notice

The rescue Telnet service has no authentication or transport encryption. Use it only through a directly connected trusted USB cable. Do not bridge or share the gadget interface with another network.
